# Shinme / 新芽 — Web UI デザインモック

計画の Phase 0 成果物。盆栽を「育てるアート」として見せる、モバイル主体のデザイン案です。本番の React、ルート、API、認証、データは変更していません。

## 開き方

[index.html](index.html) をブラウザで直接開いてください。ビルド・サーバー・ネット接続は不要です。上部の「画面」で切り替えます。

- S0: ランディング（`#landing`）
- S1: マイ盆栽（`#home`、初期画面）
- S3: 詳細・時系列タイムライン（`#detail`）
- S5: AI診断結果（`#insight`）
- S6: AI相談（`#chat`）
- トークン・コンポーネント見本（`#tokens`）

盆栽カード → 詳細 → AI診断 → AI相談をたどれます。登録・編集・削除・認証・送信などは説明通知のみで、処理や保存はしません。購入前チェック・設定・フォームは今回のモック対象外です。データ・会話・診断結果はすべて架空です。

## デザイン

深緑の構造、ストーンの余白、ライムの操作色。写真を主役にし、カードを作品のコレクションのように並べます。アイコンと盆栽プレースホルダーは自作SVGで、外部画像への依存はありません。実際のユーザー写真ではありません。

|用途|値|
|---|---|
|背景 / Surface|`#F2F1EC` / `#FFFFFF`|
|文字・暗い面 / Primary|`#12201A` / `#1E3A2B`|
|CTA・選択状態|`#C9EE6B`（文字は `#12201A`）|
|補助文字 / 境界|`#5E6660` / `#D9D7CD`|
|AIの明るい面 / 文字|`#F6EBD3` / `#6E4A0E`|
|暗い面のAIアクセント|`#E7B65C`|
|写真 / カード / ボタン角丸|24 / 18 / 16px|
|本文 / 最小文字 / 見出し|15 / 11 / 26–36px（PCランディング46px）|
|操作領域|原則44px以上、主ボタン52px|

フォント指定は Zen Kaku Gothic New と Manrope。本モックは完全にローカルで開けることを優先し、フォントを配信・同梱していません。未インストール環境では Hiragino / sans-serif で表示されます。本番導入時に計画のウェイト・`display=swap`で読み込みます。スクリーンショットの字形は検証環境のフォントです。

## レスポンシブ

- 768px未満: 2列ギャラリー、フローティング下部ナビ、登録FAB。固定幅の端末フレームは使いません。
- 768px以上: 200pxサイドバー、最大1120pxのコンテンツ、最小220pxの可変列ギャラリー。詳細は写真・情報と時系列記録の2ペインです。
- 詳細はPCでも写真・世話・診断を時系列に混在させます。
- 詳細・診断では下部ナビを出さず、戻る操作を表示。AI相談も入力欄と重ならないよう下部ナビを非表示とした案です。
- 下部固定要素に safe-area を加算。入力欄は静的モックで、本番の `visualViewport` キーボード追従は未実装です。実機検証は後続フェーズで必要です。
- 写真の構図保持は本番実装で `contain` を基本に検討します。本モックのSVGは全体が見える配置です。

## 提案として残す判断

1. 下部ナビの採否: このモックは下部ナビ案。既存ハンバーガーからの変更は未承認です。
2. ランディングの追加コピー「盆栽と暮らす。変化を楽しむ。」「GROW YOUR OWN PERSPECTIVE」は今回の提案。既存タグライン「AIが見守る、あなたの盆栽」は維持しました。
3. 削除操作は詳細末尾に配置する案です。
4. AI相談では下部ナビを隠す案です。

計画にある非公開の Claude artifact は取得できなかったため、計画書の文章から再構成しました。元モックとのピクセル一致を示すものではありません。Phase 1以降の本番導入は別作業です。
